# ราคากลางงานพิมพ์ — ยิ้มหวาน สตูดิโอ

เว็บหน้าเดียว (`index.html`) สำหรับพนักงานคิดราคาขายงานพิมพ์สี แสดงเฉพาะราคาขาย

- **งานแผ่น**: ราคาต่อใบตามขนาด (A4/A5/A6) × กระดาษ × 1/2 ด้าน × ขั้นบันไดจำนวนใบ
- **งานเข้าเล่ม**: นับแผ่น A3 ทั้งงาน (เนื้อใน + ปก) แล้วคูณเรทต่อแผ่น A3 ตามขั้นบันได
  บวกค่าเข้าเล่ม (บาท/เล่ม) และค่าเคลือบปก (บาท/แผ่น A3)
- ปุ่ม "คัดลอกใบเสนอราคา" สำหรับส่งลูกค้าทางไลน์

เรททั้งหมดเก็บอยู่ใน `<script id="rates-data">` ภายใน `index.html`
เมื่อเปิดผ่านลิงก์ claude.ai เจ้าของร้านจะเห็นแท็บ "ตั้งค่าเรท" แก้แล้วกด "บันทึกเรท"
หน้าเว็บจะถูกเผยแพร่ใหม่ ทุกคนที่เปิดลิงก์เห็นเรทใหม่ทันที (พนักงานไม่เห็นแท็บตั้งค่า)
