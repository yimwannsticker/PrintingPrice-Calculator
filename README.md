# คำนวณราคางานพิมพ์สี (ร้านพิมพ์ดิจิทัล)

เว็บแอปหน้าเดียว (`index.html`) ภาษาไทย ใช้ได้ทั้งมือถือและคอม ไม่ต้องติดตั้งอะไร
เปิดไฟล์ในเบราว์เซอร์ หรือเปิด GitHub Pages ของ repo นี้ได้เลย

- คีย์ข้อมูลแล้วราคาขึ้นทันที (ไม่ต้องกดปุ่มคำนวณ)
- ปุ่ม "คัดลอกใบเสนอราคา" สำหรับส่งลูกค้าทางไลน์ (ไม่แสดงต้นทุน)
- แท็บ "ตั้งค่า": กระดาษ, ค่าพิมพ์, ค่าเข้าเล่ม/เคลือบ, ชิ้นต่อแผ่น, % เผื่อเสีย,
  ตารางกำไรตามช่วงจำนวน, การปัดราคา, ราคาขั้นต่ำ, เงื่อนไขการเข้าเล่ม
  บันทึกอัตโนมัติในเบราว์เซอร์ของแต่ละเครื่อง ใช้ปุ่มส่งออก/นำเข้าไฟล์เพื่อย้ายค่าไปเครื่องอื่น
